Project Overview

An interactive Power BI dashboard built using GA4-style website
analytics data to analyze website traffic, user engagement,
conversions, acquisition channels, and revenue.

Note: The dataset is synthetic GA4-style data created for
portfolio and learning purposes.

Dashboard
Screenshot 2026-09-15 001307.png

🎯 Business Objectives

Analyze website traffic and user activity.

Identify high-performing acquisition channels.

Compare traffic volume with conversion efficiency.

Analyze engagement and revenue performance.

Identify opportunities for marketing optimization.

🔍 Key Business Insights

Organic Search

Organic Search is the strongest traffic and revenue contributor,
generating approximately 83.2K sessions and ₹151.4K revenue.

Email

Email achieves the highest conversion rate at approximately 5.35%,
despite having lower traffic volume.

Organic Social

Organic Social has a lower conversion rate of approximately 1.82%,
indicating an opportunity to improve the conversion journey.
